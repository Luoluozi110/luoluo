# 桃花岛·诗词楹联飞花棋（可玩版）

一款以科举为题材、纯前端的诗词楹联「飞花棋」单机桌面游戏。大富翁式棋盘行进 +
「挥毫论道」六步对决 + 六维评分 + 图鉴收集。技术栈为**原生 ES Module + Canvas 2D**，
无构建步骤、无外部依赖、无后端，全部素材（美术/音效）由代码程序化生成，离线可用。

## 目录结构

```
index.html        入口（必须使用 HTTP 访问，见下）
css/              base.css / board.css / ui.css
js/engine/        纯逻辑引擎（无 DOM）：game / rules / config / album
js/ui/            DOM 表现层：app / board / hud / battle / modals / album / svg / audio / timer
config/           全部内容配置（JSON，驱动玩法，可热改）
```

## 如何运行（重要）

本游戏通过 `fetch()` 异步载入 `config/*.json`，**不能用 `file://` 直接双击打开**
（浏览器会因 CORS 白屏）。必须用本地静态服务器：

### 方式一：Python（推荐，几乎都自带）

```bash
cd 本目录
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

### 方式二：Node

```bash
npx serve .
# 或：npx http-server -p 8080
```

### 方式三：VS Code

安装「Live Server」插件，右键 `index.html` → Open with Live Server。

## 如何部署上线

整个目录是任意静态托管平台的标准静态站点，直接上传即可：

- **腾讯云 CloudBase / EdgeOne Pages / Vercel / Netlify / GitHub Pages**：
  将本目录作为站点根目录发布，无需任何构建命令。
- 确认托管方对 `.json`、`.js`、`.css` 的 MIME 类型正确（`application/json`、`text/javascript`）。

## 玩法速览

1. 选流派（决定开局主修属性与初始文心）。
2. 掷骰行进，落格触发：平/仄韵（回灵感/涨基本功）、考题（知识考课 / 创作抉择）、
   奇遇、论战（六步对决）、天象、岔路支线、名胜。
3. 两圈后进入殿试三场（咏物 / 送别 / 怀古），全胜即「金榜题名」。
4. 累计统计与图鉴解锁存于浏览器 localStorage，可装配开局加成。

## 随时存档（本版新增）

- 对局进行中，**右上角「≡ 菜单」按钮**随时可点：
  - **保存当前进度**：手动存档到本机浏览器（localStorage）。
  - **读取存档**：从最近一次存档继续。
  - **返回主菜单**：放弃当前局回到流派选择。
- **每回合结束自动落盘**：即使直接关闭页面，下次打开也能从主菜单的
  **「▶ 继续上局」** 按钮从中断处续玩。
- 存档内容为整局运行时状态（六维、灵感、文心、棋格位置、天象、图鉴等），
  通过 `js/engine/save.js` 序列化（含 `Set` 类型的兼容处理），与配置解耦。
- 注意：进度存于**当前浏览器**的 localStorage，换浏览器 / 清缓存会重置（属本地存档特性）。

## 手机 / 移动端适配（本版新增）

- **棋盘清晰化**：手机端放大棋盘基准缩放，并支持**单指拖动平移、双指捏合缩放**，
  方便看清 60 格大环与支线名胜；拖动不会误触 HUD 与弹窗。
- **六维面板重排**：窄屏下雷达图改为置于上方、六维数值列表占满整宽，
  数值不再被挤到面板边框之外。
- 战斗台「对阵者」改为上下叠放、结算页雷达与六维改为上下排列，避免窄屏压扁。
- 弹窗 / 卷轴内边距收紧，选流派卡窄屏两列，整体竖屏可达。

## 本版相对原始原型的修复（6 项）

| # | 问题 | 修复 |
|---|------|------|
| A005 | 图鉴「桃李满园」解锁条件为 `multiplayer`（无多人模式 → 永远无法解锁，死锁） | 改为单机可达成的 `wins ≥ 50` |
| 天象 | 「金榜题名时」本是「下一场论战 +10%（一次性）」，却被塞进回合倒计时列表，HUD 显示「剩 1 回合」而后台增益静默持续到下次战斗 | 改为战斗作用域增益，单独在 HUD 展示「下一场论战 +X%」，回合倒计时不再误删 |
| 抉择题 | 超时不选仍按 `options[0]` 白拿属性/倾向奖励 | 超时不再给奖励，并照扣灵感（与知识题一致） |
| 殿试 | 殿试题材（咏物/送别/怀古）硬编码在引擎里 | 改为读取 `npcs.json` 主考官 `themes`，场次与全胜阈值同步 |
| 败北判词 | 文案写死 `−2`，但实际败北扣分为晚期的 `−3`、`科场风起` 时 `−6`，文案与实扣不符 | 引擎预计算真实扣分并传给 UI，判词精确显示 |
| 文心文案 | `palace_pct`（殿试加成）无效果文案，装配/替换时显示「效果由配置定义」 | 补全为「殿试每场得分 +N%」 |
