## 为什么没有“每站都下载”

- “免费浏览 / 免费下载”不自动等于“允许把原文件放进公开代码仓库”。
- 即时设计资源社区与 Craftpix 需要针对具体作品继续确认再分发条件；本次采用保守边界。
- Sketchfab 候选是高面数 3D 扫描件，不是可直接使用的 2D UI 图标。
- Freesound 的 CC0 条目可以商用，但公开试听版是低码率文件；它适合选型，不适合冒充生产母带。
