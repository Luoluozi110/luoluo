# 棋盘美化第二轮：桃源园景

## 改动

- 中央桃花岛保留原始插画，以浅滩、细水纹、岸石与边缘柔化连接盘面。
- 增加桃枝、荷叶、银杏、雪梅四组静态 SVG 装饰，替换旧的渐变色块树冠。
- 景观大小和位置根据当前圈层计算，进入中圈、内圈时为路线留出空白。秘密终局收起花木与浅滩。
- 起点配书院，阶段门配牌楼；兼容名胜格使用已有亭阁美术。建筑向路线内侧偏移，同圈过近的立牌自动避让，装饰不接收点击。
- 书生改为青衫、浅玉底座，适当增加尺寸，保留既有移动机制。
- 无新增图片下载、持续动画、规则或配置修改；省电档去除立牌柔影。

## 验证

- 棋盘视角与格子图标共 12 项测试通过。
- 编辑器棋盘圈层测试通过；board.js 与 board-scenery.js 语法检查通过。
- 浏览器检查 1440×900、768×1024、390×844、320×740、844×390。
- 外圈、中圈、内圈与秘密终局逐一检查：当前位置唯一、隐藏圈层立牌不显示，手机展开/收起保持正常。
- 通过临时测试配置增加一个名胜格，确认立牌存在且不覆盖任何可见路线格。未改变正式棋盘内容。
