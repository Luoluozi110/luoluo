# 构思进度与传世名篇说明优化

2026-09-10，接续 UI 首次改版。

- 棋盘 HUD 与修习顶部常显构思进度，例如 4/10，并显示进度条、下阶段进度收入和每10进度换1构思。说明进入新阶段才增加进度，不随掷骰增长；原有构思补充与结转规则不变。
- 名篇基础奖励从奖励字段生成，分支按等级列出触发时机、文体／胜负／阶段限制、具体资源或百分比。百分比使用运行时归一化值，3%不会误写为300%。
- 分支显示等级不足、已选路线下局携带可用、未选路线不生效。提示路线选定后跨局锁定；选择前可取消确认。图鉴只供阅读，路线仍在开局装配界面选择。
- 补充名篇经验来源、距下一级经验、非教学局要求，以及本局按开局等级和路线执行、升级效果下局生效的说明。文学描述放入“路线意境”。
- 手机名篇改为单列宽卡，返回按钮与标题分开；展开说明不会误切换装配状态。

验证：23项专项测试通过（名篇文案2、费用5、小整数16）。六尺寸浏览器检查通过；桌面及手机验证分支确认取消不改存档、确认后锁定、图鉴按钮不可执行、说明展开不改变装配。截图采用本地正式组件与模拟已解锁名篇，不改玩家现有存档；未覆盖实体手机和所有长局组合。
