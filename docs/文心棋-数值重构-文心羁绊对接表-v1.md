# 文心棋数值重构：全量文心与羁绊对接表 v1

日期：2026-09-05。来源：当前工作区正式配置。配合[主方案](文心棋-数值系统全面重构方案-v1.md)阅读。

本表只规定目标单位、条件保留与语义对接，不是游戏运行配置。参数沿用旧字段名便于审查，正式实现应转换为主方案的显式 trigger／target／unit 契约。数值箭头表示单位变换，不代表已经验证平衡；B阶段的条件／作用层修正另列。

## 1. 单位与阅读规则

属性、灵感、心得×10；成稿进度×1000；比例和倍率×10000以bp保存；骰点、数量、次数不变。一次完整稿页不扩大。参数 value 必须按效果类型解释。升级表的费用均是未计流派折扣的灵感基础价；0费用或0递增值必须作为有效值保留。

`reward.perMatch=false` 当前表示本场只发一次；目标改成清晰的 frequency。每级“逻辑字段”保留该等级所有非数值字段，包括布尔开关、条件和类型变化，不能只复制基础等级。
