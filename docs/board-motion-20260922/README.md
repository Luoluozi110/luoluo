# 第三轮：棋盘动态反馈与第二、三轮联合发布

## 表现

- 行进时书生轻抬、原格短暂留下墨迹；保持引擎原有 150ms/130ms 步进等待，不改玩法状态。
- 最终落点扩散一次金色水纹；静态定位框继续保留。
- 实际切换圈层时，新路线按顺序显现、阶段门短促抬升；重复同步同圈状态不重播。
- 岛边两层水纹低频变化；高画质花瓣上限从原预算 22 收束至 8，并降低速度与透明度。
- 省电和减少动态偏好关闭装饰动画；切圈、重建、画质切换清理临时动画，后台暂停环境动画。

- 12 项棋盘视角/图标测试及编辑器圈层测试通过。
- 五种屏幕尺寸：1440×900、768×1024、390×844、320×740、844×390；四种圈层状态。
- 动态检查覆盖墨迹/水纹结束后的 DOM 清理、晋升动效结束、同圈防重播、低画质、运行时减少动态偏好和模拟 visibilitychange 事件。
- 保留第二轮的立牌避让、手机面板、当前位置、省电高亮检查。
- 浏览器使用真实本地组件与配置构造测试状态；截图和结果见同目录。`node docs/board-motion-20260922/check.mjs` 连接本地 8094 端口。
