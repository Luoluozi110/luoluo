# UI 与功能文案改版交付记录

2026-09-10；对应《文心棋-UI与功能文案排查及修改方案-v1》。

## 已实施

- 三功 HUD 改为完整资源行，展示余额／容量及当前章法，移除长篇派生数值与“心策稿”缩写。
- 修习分为成长、章法、稿本、流派与记录；标题、关闭、资源和操作反馈固定在顶部，正文独立滚动。手机单列选项，桌面成长选项两列。
- 本阶段生效与下阶段安排分别显示；选择仍自动保存，不新增确认步骤。分区切换保存滚动位置，重绘保持焦点。
- 稿本按钮提前展示实际费用、实际恢复、次数和不可用原因；成稿显示动态门槛。润色、刊行、定卷分别返回明确回执。满灵感禁止零收益刊行；非法稿本操作直接拒绝。
- 文心升级统一查询引擎费用，修复奇士折扣后的可用性。升级前后效果及操作优先，联动与典故可展开，主动使用时机与被动触发类型分开说明。
- 刊行收益与灵感执行共享查询，包含奇士累积加成和上限；查询不消费累积加成。
- 三功和文心详情支持 Escape 关闭、Tab 首尾约束与关闭后焦点恢复。强制选择弹窗保持原完成方式。
- 追加骰显示实际费用、剩余灵感与准确禁用原因；手机操作单列，完整按钮名不拆行。算分规则可展开。未公开的 NPC 信息未加入提示。
- 去掉主菜单数值迁移术语和玩家界面“方案 C”字样。空技法节点不占操作区。
- 更新模块与样式缓存版本为 `20260910ui1`，避免旧界面与新费用接口混用。

- 新局、编辑器导出 numericVersion 3／工程26／74组羁绊、旧档属性53／进度1440续玩通过，无页面脚本错误。

## 复现与同步

执行 `npm run test:release`、`node --test tests/ui-cost-quote.test.mjs`。浏览器脚本为 `scripts/check-ui-readability.mjs` 与 `scripts/check-small-integer-browser.mjs`，通过 `PLAYWRIGHT_MODULE` 指定 Playwright，使用本机 Edge。

部署沿用现有 GitHub Pages main 根目录。游戏、编辑器继续共用当前云配置；本次没有内容数值变更，不重写编辑器的未发布工程。改动源文件同步到原工作区 `feihuaqi-playable`，编辑器预览使用该运行时。

回退从本次 `backup/` 带注释标签创建恢复分支；提交 SHA、标签和实际部署状态在交付消息给出。
