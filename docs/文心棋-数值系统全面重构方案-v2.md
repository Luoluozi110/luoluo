# 文心棋数值系统全面重构方案 v2：小整数与明确收益

日期：2026-09-07。状态：方案修订，未修改游戏、编辑器或线上配置，未验证整局平衡。

本版取代 v1 的单位放大决策。核心体验仍是：玩家在续掷、文心升级与长期培养之间分配资源，通过构筑和取舍完成论战。此次优先减少计算负担，保留现有资源竞争关系。

## 1. 为什么上一版不合理

已知：当前六维初始 5，灵感 36／54，追加骰 5，心得普通修习 4。v1 将它们改为 50、360／540、50、40；若奖励和价格同步乘十，玩家可行动次数完全不变。新数字中的零并没有产生新选择。

另一个问题是顺序倒置：先允许属性 +0.1，再为保存这个精度把研修放大至 3000。系统为尚未证明必要的微奖励承担了更多显示、取整、迁移和测试成本。把千点藏进进度条也不能消除配置复杂度。

本版原则：**资源只为有意义的最小行动定刻度；成长不足一点时用进度；算分精度留在计算层。** “整数”不等于“所有系统同一个分母”，尾数是 0 也不一定无效，例如 10 次中的 1 次仍有明确意义。

这些是建议目标；六维、灵感、心得、评分量级保持当前配置。无自动微成长、无新增第二种货币。研修、熟练、成稿和构思本来就存在，只改变必要的内部表示。

## 3. 三功进度：取当前公式所需的最小整数分母

下列 X、B、S 是基础属性与常驻来源之和，均为整数，不包含本场百分比算分加成。按开战／阶段快照结算，不能中途升级后重算同一事件其他来源。

### 3.1 学力：75 格研修

当前每战每位收入 `min(2, 1 + 0.04X)`，需求 3。乘 25 即得：

```text
每战每位研修收入 = min(50, 25 + X)
完成需求 = 75
完成次数 = floor((原进度 + 本次收入) / 75)
结余 = (原进度 + 本次收入) % 75
```

学力 5／10／16／20／25 的收入为 30／35／41／45／50；学力 6 是 31。25 由 0.04=1/25 决定，比 1000 更小且不损失该公式精度。现有“研修 +1”转换为 +25 格，不能改成 +1 格。

心得上限仍为 `6 + floor(X/3)`；研修位仍为 `min(3, 1 + floor(X/10) + 流派额外位 + 名篇额外位)`。例如博闻还要算起始文心博览的 +3，不能忽略常驻来源。

界面示例：“研修 60／75，本场预计 +30，可完成一次，余 15”。公式留在详情，主按钮显示实际收益。

### 3.2 笔力：40 格成稿

当前每战收入 `min(1.5, 0.05B)` 份残页，需求通常 2 份。乘 20：

```text
每战被动成稿收入 = min(30, B)
成稿需求 = B >= 16 ? 20 : 40
完成页数 = floor((原进度 + 所有本次成稿收入) / 成稿需求)
结余 = (原进度 + 所有本次成稿收入) % 成稿需求
```

现有残页 +1／+0.5 分别为成稿 +20／+10；完整稿页 +1 仍为 +1 页。T007 满级的残页奖励、T040／S10 的奖励都按各自频率结算，不能将一次进度奖改为完整页。

笔力 5 时八场被动收入合一页。笔力 15 时每战 15／40 页，16 时每战 16／20 页，产速约变为 2.13 倍。**这是原机制的阈值跳变，单位压缩不会修好它。** 基线保留此门槛；另设单变量试验：固定需求 40，收入候选 `min(60, B + max(0, B-12))`。它在 B=15／16／20 时收入为 18／20／28，削弱旧加速门槛附近产页，不可宣称等价。必须比较稿页产出、求心、润色和定卷频次后再决定是否采用。

稿匣容量保持 `min(8, 2 + floor(B/6) + 流派额外容量)`。一骰胜 2 页、多骰胜和平局 1 页、失败 0 页但补 +20 成稿，均保持原语义。先合成再限容，整页溢出记录但不储成可重复领取的进度；不足一页的余量保留。

润色 2 页减费 2、发表 3 页回灵 4、定卷 5 页得 60 终局分，最多 2 卷。笔力 24 阶段额外页与 32 定卷返页保留。

### 3.3 思力：10 格构思

```text
阶段收入 = 10 + S + 流派额外次数×10
合计 = 原结余 + 阶段收入 + 本阶段合法的一次性额外次数×10
可用次数 = min(次数上限, floor(合计/10))
结余 = 合计 % 10
次数上限 = min(6, 3 + floor(S/10) + 流派与名篇上限加值)
```

思力 5、无其他加成时，各阶段收入兑现 1、2、1、2 次。新阶段重设可用次数，未用次数不累加，只有不足一次的结余保留；超上限的整次收入不转为其他资源。名篇开局奖励仅在开局加入，不能每阶段重发。

徐行拾句消耗 1 次得 +20 成稿；留白养气消耗 1 次减少 2 灵感败北损失；换韵生新消耗 1 次得 +6% 作品加成。奇士阶段首次免费按原频率处理。

### 3.4 不强迫三种进度统一为 100

研修 75、成稿 40、构思 10 分别有明确的数学原因。强改为 100 会产生新的小数或真实节奏变化。跨系统只比较“还有几场／几阶段兑现”，不直接比较 30 格研修和 30 格成稿谁更值钱。

## 4. 微奖励和成长递减

**首轮采用：保留完整属性 +1，把新设计的轻量奖励放进已有进度。** 例如“研修 +5 格”相当于一次研修需求的 1/15；“成稿 +5 格”相当于普通一页的 1/8。它们是新奖励候选，不能据此把所有旧属性 +1 偷换成进度 +1。

小整数会限制同类升级的细分，这是接受的代价。文心升级可通过触发范围、次数、条件和额外效果形成差异，不强求每级都提高同一个数字。T001 心得 2／3／5、T004 学力 3／4／6 均保留；这些升级自身是否过强仍要看触发率和剩余战数。

现有递减有真实问题：34／48 档位即使计算出 0.5／0.25，也可能被每事件最少 +1 抹掉。v2 单列一个后续候选，不混进表示等价验收：

- 每个属性保留 0～3 格“成长积累”，4 格兑现 +1 属性。
- 每一个名义 +1 成长按当前已兑现属性所在档位产生 4／2／1 格；每处理一点立即兑付再判断下一点档位。
- 去掉每事件最少 +1，余量跨事件保存；常驻文心属性和升级来源不进入该递减入口。
- 轻奖仍优先给研修，不引入小于一格成长积累的奖励。若上游成长修正仍生成非整数名义收益，必须单独定义其量化规则，不能直接接入本候选。

例：属性 34 时两次名义 +1 才实际 +1；48 时四次实际 +1。属性 33、余量 0，名义 +3 依次收入 4、2、2 格，最后为 35、余量 0。拆成三次输入也应一样。玩家须看到“成长积累 2／4”，不能显示 +1 却只存入半点。

这会放慢后期成长，可能影响传承、评级与通关；正式启用前独立模拟。当前游戏递减规则在本次文档交付后没有变化。

## 5. 费用：先让人能直接判断买不买

保留当前小整数价格、免费条件和取整语义。费用预览和实扣共用一个函数，展示基础价、固定减费、比例折扣、最低价、最终费用；不得先扣再判断合法性。

奇士八折价示例：原价 4／5／7，经向上取整后实付 4／4／6。因此原价 4 的八折没有实际优惠，应显示“本次实付 4，取整后未减价”，而不是虚称省了 20%。v1 改为 32／40／56 实际是降价与改变精度，不是更准确地显示旧规则。

首轮不增加灵感小数钱包、折扣余额或兑换货币。若“每次八折必有可见收益”确实是流派目标，另测“升级固定减 1，最低 1”方案；原价 4／5／7 变 3／4／6，明确比较低价增强、高价减弱。未采用前仍按现有比例和顺序。

S04 未被费用入口读取的问题仍须修复；不能以减少数值复杂度为由删除应有效的羁绊。折扣触底后说明实际贡献，免费与最低价的优先级按现有契约保留、单独测试。

## 6. 战斗计算：不放大分数，不迫使玩家手算乘区

保留当前战斗分单位和取整边界。三体均值可在内部改写为分式，避免提前显示一个近似均值参与下一步计算：

```text
格律 = round((7×三体总和 + 9×选中文体)/3)
底盘 = 格律 + 4×三功总和
```

六维均 5 时底盘 110。当前诗一骰 1～6 点对应 +3.4%、+6.8%、+10.2%、+20%、+25%、+30%，无其他来源时作品为 114、117、121、132、138、143。继续用 1100 或把整个战斗压成十几分，都增加不必要的迁移与平局风险。

建议第一步把诗一骰做成准确查表提示，玩家看到“2 点，本次 +7 分”，展开看到 +6.8%。若文心改变骰倍率、骰点或规则，必须从实际配置重算，不能固定套原表。多骰、词和联也从各自真实公式预览，不复用一骰表。

可另测简化成 +3%、+7%、+10%、+20%、+25%、+30%；即使初始底盘结果相同，其他底盘也会不同，不能直接认定等价。

普通骰区、作品修正区和明确终结倍率仍按作用对象分开；T026／S41 属性层和 S22 作品层不重复应用。内部整数比例可以使用 bp 或分式，编辑器显示 8%，账单显示实际贡献分。这里没有要求重写全部浮点、概率、计时、随机数或舍入规则。

v1 的战斗 B 公式不能照搬：本版不扩大属性或战斗分，也不借单位变化移动取整时点。胜负、平局比例、NPC 固定分、借招牌与终局评级首轮均保留当前尺度。

## 7. 文心、羁绊及外围系统如何接入

v1 对触发条件、效果目标、来源去重、开战快照、升级净差、存档事务的分析仍有价值；其 SEM-01～10 继续逐项核查。它们是语义修正任务，不因取消乘十而取消。以下表完全取代 v1 附表的“旧→新单位”列，不能先应用 v1 再除回去。

| 原配置语义 | v2 目标 | 示例 |
|---|---|---|
| 属性、灵感、心得、绝对门槛、固定战斗分 | 原值不变，标明目标资源 | T001 Lv1 获胜心得 +2；T004 学力 +3 |
| 研修连续进度 | 原值×25 | 研修 +1 → +25 格 |
| 残页连续进度 | 原值×20 | S10 残页 +1 → +20 格 |
| 构思连续收入／余量 | 原值×10 | 0.5 次结余 → 5 格 |
| 完整稿页、可用构思、等级、槽位、次数、骰点 | 原值不变 | 定卷仍 5 页，不是 100 格 |
| 比例、倍率、概率 | 强度不变；编辑与计算单位明确区分 | 0.08 编辑为 8%，内部可存 800 bp |
| 终局分和评级门槛 | 原值不变 | 定卷 60，文宗 4300 |

T007 满级成稿 +20；T005 条件减费 2／3／3；TA08 基础价 4／3／2、递增 2／1／0；S39 指定词胜心得 +2；S47 殿试入场灵感 +9。零费用、零递增与胜利条件均保持，不能用默认值覆盖。

S10／S18 等“残页”必须准确命名为成稿进度；两个 +20 在笔力不足 16 时合一页，不是两页。v1 的 817 处单位映射核查只证明旧方案的分类工作，**不代表本版全量配置已经生成或验收**。

事件、天象、名篇、流派、NPC、传承、排行榜中的原属性与资源无需批量修改。仅实际读写三种连续进度的字段需要适配。`study_bonus` 在某条路径实际发心得时保持原数，不能因为名称像研修就乘 25。效果类型、资源与消费入口共同决定单位，未知路径停止转换。

## 8. 实施分层与旧档兼容

1. **表示基线**：小资源原值保留；三种进度按各自单位换算，补费用及收益明细。要求回放等价，不改变舍入、频率、上限与随机序列。
2. **语义修复**：逐项修复 SEM 问题，每项记录具体增强或削弱，确保配置、编辑器、seed、云内容与存档契约一致。
3. **平衡试验**：分别试成长积累、笔力平滑、升级减 1、骰面整百分比；一次只开启一个变量。本文给了明确候选，但没有批准全部成为正式机制。

采用描述性规则包 ID，例如 `small-integer-v2`，实施时再分配未占用的运行版本号。三种进度的换算元数据分别写 25／20／10；禁止一个 `progressScale` 同时解释三者。游戏旧存档版本与此规则包 ID 独立。

旧局继续使用其内容快照，新局使用新版最安全。旧档若有 1.23 之类无法整除最小格的历史余数，**不能四舍五入冒充等价迁移**：旧局继续旧规则，或由专门适配保存精确分子／分母直到结清；不得让所有新局为迁就旧余数永久使用千点制。旧临时来源、非整数属性、负数或未知配置也先分类，不默默截断。

如未来实装 v1 的十倍数值局，必须按来源版本明确迁移，不能仅看“值大于 100”猜单位。历史日志不正则替换数字，旧榜不改分，新规则有独立评分版本。预览不得发奖，重载不得重发，次数已耗尽后升级不得重置。

## 9. 本轮验证和后续验收

本次随附 [算术核查脚本](verify-numeric-v2.mjs) 与 [核查记录](文心棋-数值重构-核查记录-v2.json)。脚本检查当前基础配置、单位换算的公式等价、长期进度守恒、示例费用、诗一骰样例及成长积累候选的拆分一致性，并记录配置指纹。

脚本覆盖整数属性 0～60、每值 200 次收入：验证无上限原始进度的完成次数与余量守恒；成稿另按 16 门槛选择需求。它没有跑整个游戏，也没有模拟满稿匣、奖励叠加、三功变动、历史存档或玩家策略；因此不能据此宣称全部迁移等价或已平衡。

后续上线必须比较：同事件流下表示基线的行动／支付／胜负／评级一致；语义修复的差异逐项可归因；各流派的成长、灵感支出、稿页溢出、构思浪费、升级选择率与传承增长。新增候选先按单变量运行，再测组合，不能把平均战力接近当作平衡。

试玩重点只问三件事：能否说清本次实际拿到什么；能否预估下一次完整成长；能否直接判断续掷／升级的实付成本。记录耗时与误解，再决定是否还要简化公式。

本次交付仅为 v2 方案及可复核算术材料；优先阅读第 2 节单位表、第 3 节三功和第 5 节费用。v1 保留历史参考，其扩大尺度、迁移及 UI 示例均已被本版替代。
