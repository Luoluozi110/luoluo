# 《文心棋》灵感骰文心改动方案

> 本文仅整理原定设计方案，不包含代码实现、编辑器同步或线上部署说明。

## 一、设计目标

当前灵感骰文心主要存在三类问题：

1. 效果集中在固定点数、固定百分比或简单乘区，容易出现明显最优解。
2. 学力、思力、笔力与文心效果之间缺少行为差异，玩家通常只追逐当前数值最高的选项。
3. 追加灵感骰虽然提高收益，却缺少“何时继续、何时收笔”的判断张力。

本次调整将灵感骰文心从“稳定加成”改为“骰组构型”。玩家需要根据首骰、续骰顺序、总点和风险承受能力做选择；不同文心之间可以联动，但不应互相替代。

## 二、保留不变的文心

以下两枚文心保持原有效果与升级路线，不参与本次调整：

- **梦笔生花**：每枚最终为 6 点的灵感骰提供原有收益。
- **笔落惊风雨**：每枚最终为 6 点的灵感骰提供原有主动收益。

保留它们作为“追逐六点”的明确构筑核心，使新构型与既有六点构筑并存。

## 三、文心效果调整

### 1. 急智：低开高走

将原本的低点抬升改为“先抑后扬”的机会型效果。

- 首骰为 1—2 点时，首次追加骰少消耗 2 点灵感。
- 若追加骰为 5—6 点，本场作品得分额外 +10%。
- 低开时鼓励玩家承担追骰风险；非低开时不提供无条件稳定收益。
- 升级方向：提高高点命中收益、扩大可判定的低开范围，最高建议为 +22% 左右。

### 2. 天马行空：三骰各异

将“每多一种不同点数”的线性加成改为完整构型奖励。

- 首枚追加骰少消耗 2 点灵感。
- 当本场最终拥有三枚骰，且三枚点数全部不同时，作品得分 +15%。
- 构型完成后额外获得 0.5 残页，每场一次。
- 升级方向：提高构型得分至约 +22%，或将残页收益提高至 1；不再按每种点数重复叠加。

### 3. 文思泉涌：逐骰递升

将简单的“每枚追加骰加成”改为关注顺序的连续构筑。

- 首枚追加骰少消耗 1 点灵感。
- 每一枚追加骰都高于前一枚时，每次递升使作品得分 +5%。
- 三枚骰形成严格递升时，再额外获得 +10%。
- 完成三骰递升后获得 1 点灵感回响，每场一次。
- 升级方向：提高每次递升或三骰高潮奖励，但不提高基础骰收益。

### 4. 七步成诗：合七成句

由“首骰保底”改为低成本、可追求的精确命中。

- 首枚追加骰免费，不消耗灵感。
- 前两枚最终骰点数合计恰好为 7 时，作品得分 +18%。
- 命中后获得 1 点心得，每场一次。
- 升级方向：将得分提升至约 +30%，心得提升至 2；不改变“合计恰为 7”的核心条件。

### 5. 语不惊人：高低两极豪赌

保留高点奖励与低点惩罚并存的风险定位，但升级不再逐渐抹平惩罚。

- 每枚 5—6 点骰使作品得分 +14%。
- 每枚 1—2 点骰使作品得分 −7%。
- 升级时优先提高高点奖励，同时保留并适度加深低点惩罚。
- 建议升级终点约为“高点 +24%、低点 −10%”，让玩家明确感受到豪赌性质。

### 6. 一气呵成：自动续章

将“每枚追加骰固定加成”改为一次性、无额外交互的连写效果。

- 玩家支付第一枚追加骰后，自动免费追加第二枚骰。
- 不新增第二次确认弹窗，第二枚骰直接显示在当前骰组中。
- 若自动追加骰点数不低于第一枚追加骰，作品得分额外 +4%。
- 升级方向：提高自动骰命中时的奖励，最高建议约 +10%。
- 该效果仍受本场追加骰上限约束，不能无限连写。

### 7. 倚马可待：总点分档

将单一高阈值奖励改为“投入—回收”并存的分档豪赌。

- 主动消耗建议为 3 点灵感。
- 三枚骰总点达到 12：作品得分 +16%，返还 3 点灵感。
- 总点达到 16：改为作品得分 +30%，同样返还 3 点灵感。
- 未达到 12 点时，不获得额外收益，形成明确的风险边界。
- 升级方向：提高两个档位的得分，不降低 12 / 16 的核心阈值，以免失去豪赌辨识度。

### 8. 布局谋篇：保持地图定位

布局谋篇不是论战灵感骰文心，不纳入本轮战斗骰构型调整。

- 保持其指定移动骰的地图规划功能。
- 文案统一为“回合掷移动骰前指定落点”。
- 在编辑器中保持 `planned_dice` 类型，避免被误显示为创作骰效果。

## 四、联动关系

### 低开翻盘链

“急智”负责识别低开并降低追骰成本；若追出高点，可与“梦笔生花”或“笔落惊风雨”形成高点收益链。急智本身不改写骰面，避免覆盖其他六点文心的判定。

### 异点构型链

“天马行空”要求三骰各异，和“同点”类文心天然分流：玩家需要在异点、同点、六点之间选择构筑方向，不再让所有文心都追逐同一种骰面。

### 顺势成长链

“文思泉涌”要求骰点逐步上升；“一气呵成”自动补出第二枚骰，可以帮助形成递升构型，但自动骰结果仍有不确定性，因此不会变成必然最优解。

### 精确命中链

“七步成诗”追求两骰合七，适合灵感有限但愿意追求精确条件的玩家；它与三骰总点豪赌互为替代，而非叠加为单一路线。

### 高风险回收链

“倚马可待”以 12 / 16 总点分档决定收益，灵感回收使成功时可以继续经营后续战斗，但失败会损失主动成本，形成 roguelike 中可理解的风险—回报选择。

## 五、数值与体验边界

- 所有构型奖励应在结算明细中显示触发条件与实际收益。
- 追加骰仍使用独立乘区，不替代普通骰的点数贡献。
- 自动续骰不产生额外确认步骤，只在当前骰组界面展示结果。
- 低概率高收益效果应搭配明确的失败成本，避免成为无脑按钮。
- 升级优先扩大玩法差异与联动价值，不单纯把百分比无限上调。
- `梦笔生花`与`笔落惊风雨`作为六点构筑锚点保留，其他文心围绕顺序、总点、异点和风险进行分工。

## 六、编辑器字段建议

编辑器需要支持以下骰组类型及字段：

| 类型 | 关键字段 |
| --- | --- |
| `low_then_high` | `lowMax`、`nextHighMin`、`value`、`conditionalFirstCostDiscount` |
| `all_distinct` | `minDice`、`value`、`firstCostDiscount`、`reward` |
| `ascending` | `perStepValue`、`fullDice`、`fullValue`、`firstCostDiscount`、`fullReward` |
| `exact_total` | `diceCount`、`total`、`value`、`firstExtraFree`、`reward` |
| `extra_dice_chain` | `compare`、`value` |
| `total_tiers` | `tiers[].threshold`、`tiers[].value`、`tiers[].reward` |

编辑器导出时必须保留这些字段；游戏端读取时应按类型分派，不能将未知构型降级为固定值或普通 `extra_dice_pct`。
