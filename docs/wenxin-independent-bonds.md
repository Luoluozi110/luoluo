# 独立双文心羁绊覆盖

更新日期：2026-09-04。

## 验收口径

每枚文心 A 至少与两位不同伙伴 B、C，分别构成两条不同 ID 的羁绊 A+B、A+C。每条只需这两枚文心即可激活，不依赖第三枚。单条 A+B+C、重复的 A+B、重复羁绊 ID 均不计为两条。

目前 61 枚文心全部达标。共 74 条羁绊：62 条双文心羁绊、12 条原有三文心羁绊。保留 S01–S48 的组成与效果，新增 S49–S74 共 26 条独立双文心羁绊。修改前有 34 枚文心不足两条独立羁绊，总共缺少 52 个伙伴连接；新增 26 条恰好补齐，不用重复组合充数。

## 效果与查询

新增得分效果以条件性 6%–10% 为主，沿用 `synergy-resonance-v2 / max`：同组同时达成时只取最高得分。恢复与成长奖励按各自的触发条件及次数限制结算。保留骰组、连捷、换体、题材、低灵感恢复等不同路线。

获得文心时，可查看每条相关羁绊的组成、缺少的成员与效果；右侧文心栏“查看图谱”可再次查询。编辑器“羁绊”页可编辑全部 74 条。旧 25 条或 48 条的本机缓存会补齐缺失项，不覆盖已存在记录的用户修改。
