# 小整数数值系统 v2.1

2026-09-09。规则标识 `small-integer-v2.1`，数据格式 `numericVersion: 3`，编辑器工程版本 26，新存档版本 11。

部署目标：[游戏](https://luoluozi110.github.io/luoluo/) · [编辑器](https://luoluozi110.github.io/luoluo/feihua-editors/) · [旧局续玩](https://luoluozi110.github.io/luoluo/legacy/numeric-v2/index.html)。沿用已有 GitHub Pages 主分支部署。

## 实施内容

| 系统 | 新单位与规则 |
| --- | --- |
| 六维属性 | 初始各 5，流派额外 3，文心和造诣另计 |
| 灵感 | 初始 36，上限 54，普通追加骰基础费用 5 |
| 心得 | 胜/平基础 3，败基础 2；获胜、平局、研习文心的对应奖励进入心得 |
| 研修 | 每位每场 `min(50, 25 + 学力)`，75 进度成长 1 属性，余数结转 |
| 构思 | 每阶段 `10 + 思力 + 流派额外充能×10`，每 10 进度兑现 1 构思，余数 0—9 |
| 成稿 | 每战 `min(30, 笔力)`，通常 40 进度成页；笔力达到 16 后阈值为 20 |
| 百分比 | 配置仍以整数 bp 保存，运行时与编辑器显示层还原比例；不随资源缩放 |
| 终局评级 | 保持原分数量级，稿页、次数、骰点、回合均为计数 |

以当前云端内容为基准同步 61 枚文心、263 个等级、74 组羁绊，保留终局成卷、支线人物、题库与既有叙事修改。原对接文档的 48 组羁绊不是本次发布的最终数量。

修正了六点骰得分逐骰叠加但奖励每场一次、递升前缀与完整连升加成、S18 条件成稿奖励、S21/S28 战后心得与下一战奖励。换体得分、连捷、上场未胜修正分别按声明分组取高；心得与恢复使用独立资源分组。分组归并不再依赖会随数组删除改变的下标。

同场成长采用开战属性快照；心得和稿页记录应得、实得、溢出。重复结算不重复发奖；费用不足或非法费用不改变资源；低灵感恢复先按统一快照判断，再执行灵感托底。永久扩容保留先取得者，同组不重复扩容，升级仅增加差值。

四项试验继续关闭：成长小数账户、平滑成稿曲线、固定升级折扣、骰子百分比取整。

## 存档与编辑器

旧局不直接除十或截断。主菜单续玩旧档会进入冻结的数值 v2 引擎，保留旧配置、属性和进度。开始新局前，旧自动、手动、教学档原样复制到独立 `feihua_legacy_v2_` 存档槽。旧传承留在旧规则入口，新规则使用独立传承记录。

编辑器默认种子、工程格式和游戏读取端同步；低版本工程不能覆盖新版。浏览器中已有旧编辑缓存的用户需先备份未发布修改，再从云端拉取。代码保留旧缓存发布护栏，未自动删除未发布编辑内容。模块缓存使用统一发布版本，避免混用新旧运行时。

## 验证与已知限制

- `npm run test:release`：18 项全部通过，包括所有 263 个等级的代表骰组结算、最终评级等价、升级差值、资源分组、存档和编辑器数值往返。
- Edge 无头浏览器：新局实际 HUD 为灵感 36/54；编辑器导出版本 3/工程 26、74 组羁绊；旧局属性 53 和研修进度 1440 原样续玩；无页面脚本错误。
- 完整旧测试集尚未全部适配。基线为 87 项、54 通过、33 失败；本次完整执行为 103 项、82 通过、21 失败。失败清单见 `numeric-v21-validation.json`。涉及旧单位断言、静态版本/文案断言、工程路径和旧配置假设，不得据专项验收宣称完整测试集全绿。
- 本次验证没有替代长局平衡模拟和多人长期试玩。

复现：`npm run dev` 启动本地游戏与编辑器；`npm run sync:editor` 从现工程再生成种子；`npm test` 执行完整旧测试集。浏览器验收脚本为 `scripts/check-small-integer-browser.mjs`，需 Playwright 和 Edge，可通过 `PLAYWRIGHT_MODULE` 指定本机 Playwright 模块路径。
