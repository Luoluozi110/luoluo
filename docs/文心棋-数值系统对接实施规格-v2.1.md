# 文心棋数值系统对接实施规格 v2.1

日期：2026-09-07。状态：设计规格及静态核查，不是已实装规则，不代表整局平衡已通过。

继承 [v2 小整数方案](文心棋-数值系统全面重构方案-v2.md)。本版细化文心、等级、羁绊、三功及外围系统；遇到单位冲突以本文及本次全量表为准。目标是让每个来源都能回答：何时触发、作用于什么、实际到账多少。

配套：[61 枚文心与 48 组羁绊全量表](文心棋-文心升级羁绊全量对接表-v2.1.md)、[逐字段对接数据与来源快照](文心棋-数值系统对接数据-v2.1.json)、[生成脚本](build-numeric-v2-integration.mjs)、[核查脚本](verify-numeric-v2-integration.mjs)、[验收记录](文心棋-数值对接验收记录-v2.1.json)。

## 1. 本版锁定什么

| 决定 | 对接方式 |
|---|---|
| 属性、灵感、心得小整数 | 初始 5、36／54；心得修习 4，追赶 3，专精 5；无十倍换算 |
| 三种连续进度分开 | 研修旧值×25、满75；成稿旧残页×20、满40或20；构思余量×10、满10 |
| 文心成长的真实去向 | 指定文体胜利、平局补偿、非胜修学的目标分别为明确条件下的心得；不同时再发直接属性 |
| 原值与规则修正分层 | 表示基线复刻现代码；语义修复另有差异编号；平衡候选默认关闭 |
| 完整离散收益不换算 | 完整稿页、构思次数、熟练、技法经验、槽位、等级、阶段和骰点仍原值 |
| 百分比与作用层分开 | 8%=0.08，3.5%=0.035；编辑器填8或3.5，审查数据保持原比例，不强行取整到整百分比 |
| 不凭感觉重做所有等级 | 61 枚文心的 263 条等级效果及费用先保留；每级条件变化、零值、开关完整保留 |

本版新增的规则决策属于建议发布目标，必须通过实现验收才生效。v2 中的成长积累、笔力平滑、升级固定减1、骰面简化四个平衡候选仍关闭。

## 2. 资源与入口契约

### 2.1 最少需要明确的字段

每个可执行效果由 `sourceId + effectId + trigger + condition + target + amount + frequency + stack + snapshot` 描述。这里是新契约规格，不声称当前加载器支持这些字段。

| 字段 | 必须表达的含义 | 例子 |
|---|---|---|
| sourceId / effectId | 稳定来源与子效果；升级不换ID | T007 / T007-manuscript |
| trigger / condition | 事件与条件分别判断 | battle_reward；最终骰至少一个6 |
| target / amount | 资源单位与值 | manuscript_progress / 20 |
| frequency | 一战一次、按命中次数、每局N次等 | once_per_battle |
| stack | 加算、取高、互斥；分数组与资源组分开 | add；low-inspiration-recovery:max |
| snapshot | 从哪个时点读取 | final_dice / battle_start_attrs |
| receipt | 名义、实际、溢出和剩余限次 | 名义20格，合成结果另记 |

例如 T007 Lv5 拆成“每枚六点作品修正 +16%”和“本战出现六点成稿 +20 格，每战一次”两个效果。两枚六点使前者 +32%，后者仍 +20。升级前已经用过的次数由稳定 effectId 继承。

完整目标参数表保留旧 `perMatch`、`stackGroup` 等供对照；实现时要编译成上述显式契约。不可把对照 JSON 直接写入正式配置。

### 2.2 统一资源入口

| 入口职责（拟新增或整合） | 输入与结果 | 禁止行为 |
|---|---|---|
| grantInsight | 小整数→容量截断→到账账单 | 截断部分自动换成研修、再触发一次心得奖励 |
| grantStudyProgress | 指定属性研修格→75兑成长→余量保留 | 将研修位所有属性都加一遍同一份定向奖励 |
| grantManuscriptProgress | 成稿格→按快照需求合页→容量截断 | 把成稿格直接计入持稿增伤 |
| grantManuscriptPages | 完整页→稿匣容量 | 将一页再乘20输入页数字段 |
| grantStrategyCharges | 可用次数→次数容量 | 与不足一次的蓄积字段混用 |
| grantAttributeGrowth | 名义成长→当前递减→实际增长 | 常驻文心卸下/升级也套成长递减 |
| quote / pay | 同一合法性及费用账单→一次扣款 | 预览扣款、取消后部分执行、两个cost字段重复扣 |

资源“实际到账为0”不代表事件未发生。一次性获得、限次奖励和稿页溢出默认消费该次触发；明确互斥组未胜出的候选不消耗限次。界面同时显示实际0及原因。

## 3. 文心按机制对接

### 3.1 常驻属性与基础成长

T004／T006／T008／T009 使用 `attrs` 作为权威属性映射。T004 同时有 `attrs.xue=3` 与 `value=3`，后者是旧兼容信息，不允许两次加3。

获得与升级只改来源净差，卸下移除对应来源。博览 3→4，学力净 +1；研修收入因此每场 +1 格，心得容量和研修位只有跨各自门槛才增加。升级预览分开显示“属性净增”和“达到门槛后的额外效果”。

常驻属性参与日常三功；天象或文心的百分比算分属性不反馈到研修产速。成长入口读取的递减属性集合必须在实现时固定；v2 的四格成长候选以已兑现基础成长判断，不能用战斗临时属性提前跨档。

### 3.2 心得类

| 文心／羁绊 | 目标触发与资源 | 关键边界 |
|---|---|---|
| T001～T003、T012～T014 | 以指定文体获胜→心得，数值保留 | T001 2／3／5；文案不再写诗力 |
| T018 曲水流觞 | 平局→心得3／4／6 | 败北不领平局奖 |
| T027 转益多师 | 平或负→心得，另登记下一战修正 | 不复用旧补偿属性路径 |
| S02／S39 | 指定词胜→心得3／2 | 当前已有胜利判断，不误报为平败也领 |
| S21／S28 | 平或负→心得2／1；nextBattlePct另处理 | 全体成员齐备；下一战修正同类取高 |
| T037、S13／S25／S27 | 有上一场且实际换体→心得 | S25只在词联互换；首战无换体奖励 |

选择保留心得作为成长中介，是为了让玩家决定培养哪项、是否留给博闻求心。不能把额外心得默认兑现到当前文体，否则又形成自动滚雪球。

### 3.3 骰组、费用与成稿

所有骰型的条件、最少骰数、等级变化均见全量表。三个计数不能合并：自然骰序列、最终骰序列、从购买入口追加的次数。免费购买也记一次；主动送骰另记来源。

- 低开高走读取自然首骰和第一枚自然续骰；改骰不能伪造低开。费用判定也读同一自然首骰。
- 六点、对子、异点、高低同现、首尾相同读取最终骰。
- T016 连升按当前前缀连升规则核算，每次连升先计perStepValue，满足满骰条件再叠加fullValue并使用fullReward；不是看到任意一对升序就获得满档。
- TA06 的12／16点档取最高满足档，奖励也仅该档一次；S20 的 min 和 S43 的 threshold 在编译时统一为总点门槛。
- T010 成稿0.5→10格；T007满级、T036／T040及部分羁绊的残页1→20格；等级中1.5／2／2.5／3残页分别为30／40／50／60格。

**本次纠正历史方案的一处计数判断：** 当前文心 `dice_pattern:six` 按六点数量计分，T040也走该路径；羁绊 `six` 是存在一次。目标先保留这个差异，卡面明确“每枚六点”或“出现六点”。T040的资源 `perMatch=false` 仍只发一次。v1 把T040得分视为存在一次的叙述不再采用。

### 3.4 续航、容量与传承

T017 胜利回灵、T019／T029 回合恢复、T030 答题恢复、T031 战后低灵感恢复分别保留独立事件。不要因为都加灵感就共用频率计数。T019 的 onTalent 是另一条“新得文心”事件，升级不冒充新获得。

T032／T033 的 `inspiration_capacity` 当前是同组首次获得扩容、升级处理差值、卸下不回退的永久账本。表示基线保留它，不改成“同时持有时两者相加”，也不默认为同组自动取最高。若要改为最高历史扩容，应作为独立规则变更。

填充灵感按当前 `round(本次合法扩容量×fillRatio)`，只填本次差值；例如14×0.5=7。永久上限已经记账后重载或重新获取不重发。容量升级与获得之间的回填顺序需单独回放。

T034 门槛40／36／32／28／24／20，继承率80%／84%／88%／92%／96%／100%，起始灵感8／8／10／10／12／12保留。继承基础修为与允许继承的永久成长；装备来源不再次复制。旧档无法分解来源时继续旧局，不能猜测扣除。

### 3.5 主动文心

| 对象 | 费用与执行约束 |
|---|---|
| TA02 | fraction只借招牌，固定分与比例分别处理；无可借目标先判合法性 |
| TA03／TA04 | 发动后按最终骰计算，负面修正保留符号；不能被max正数过滤 |
| TA05 | 顶层cost为发动价，effect.cost作为兼容别名核对；续写状态一次，refund战后一次 |
| TA06 | 等级生效费用及总点档各自读取；不同时领两个档奖励 |
| TA07 | 保留可改骰上限的逐级变化，自然骰不改 |
| TA08 | 地图价=baseCost+本局已用次数×costStep；顶层/effect.cost不再额外扣一次；costStep=0有效 |
| TA09 | 先检验可封，再扣费；penalty从负数逐级趋零，零不能恢复默认负值 |
| TA10 | 首骰保底和禁止追加一起锁定；保底4升5是规则升级，不是属性成长 |
| TA11 | 满足最少骰数再发动，最低/最高改骰采用稳定索引，费用只扣一次 |

全量表的发动价是等级基础价，不含地图次数递增；不能据此把TA08各次使用都收同一价。TA01虽以TA开头却是被动，以kind为准。

## 4. 羁绊叠加与失效保护

全部48组维持成员和ID，成员用持有ID集合判断，不以同名或重复副本充数。升级不重算“首次激活奖励”，卸下后不再获得新战斗收益，已经合法发出的永久奖励不回滚。

以下为语义修复层目标，表示基线仍保留原stack行为：

| 组 | 目标规则 |
|---|---|
| S13／S25／S27 | 换体作品修正取高，换体心得另取高；两个赢家可不同 |
| S15／S26 | 连捷作品取高；S15的对子回灵仍独立 |
| S06／S21／S28／S32 | 仅“上一场非胜”的作品效果取高；其他子效果独立 |
| S12／S32 | 低灵感回复按同一快照选有效候选，取高；限次已耗尽不参选 |
| S21／S28与T027的nextBattlePct | 下一战修正取最高，下一战消费一次；心得来源按自身规则 |
| 其他独立来源 | 同作用层加算；相同effectId去重；明确终结倍率仍取高 |

S22只进作品层，T026／S41只进六维算分层；不能同时放大底盘又放大作品。T022只放大气势，T011只复制其规定的亲和来源。取消大范围 `synergy-resonance-v2:max` 后会增强多羁绊构筑，必须记录单组合差异。

同组取高并列时按effectId字典序选一个，只有选中资源效果消费次数。负面修正单列，不被正数取高消除。资源与分数拆成不同子ID，分数被覆盖不等于整个复合效果失效。

## 5. 三流派与文心经济

下表假设普通新局、无名篇和传承加成，已应用起始文心。

| 流派 | 起始关键属性 | 每位研修/位数/心得上限 | 阶段构思收入/上限 | 被动成稿/需求/稿匣 |
|---|---|---|---|---|
| 博闻＋博览 | 学力5+3+3=11 | 36格／3位／9 | 15格／3次 | 5格／40格／2页 |
| 奇士＋推敲 | 思力5+3+3=11 | 30格／1位／7 | 31格／5次 | 5格／40格／2页 |
| 辞宗＋入木三分 | 笔力5+3+3=11 | 30格／1位／7 | 15格／3次 | 11格／40格／4页 |

博闻求心花8心得（45%配置概率），与普通培养两次竞争；奇士花2次构思（40%），与章法使用竞争；辞宗花3页（50%），与发表、润色竞争。配置均为每局最多2次、每阶段最多1次。概率、保底配置是否被实际入口读取须实装验收，不将配置概率当作已实测获得率。

博闻知识门槛2、心得奖励4、首次凑齐两种文体心得2保留。辞宗阶段首次一骰额外页的当前代码判断不要求获胜；这与“首次成稿”的名称可能冲突。表示基线保留真实判断，语义版文案明确“一骰结算每阶段首次”，若改成胜利需另记强度变化。

奇士正向灵感+20%已有结余累积器，不是本版新增货币。对整数合格收入可用0～4的五分之一余量：每收到1点合格收入增加1格，满5另发1灵感。开局、文心直接来源与传承等排除范围按当前入口核对，不能笼统写“所有回灵都+20%”。当前用reason文字排除，目标改成明确reasonId与eligible标记；先保持相同资格集合。

当前按合格名义收入计累积，即使回灵被容量截断也会推进累积器。基线保留；若要按实际到账累计，是独立平衡改动。新增奖励入库时必须声明是否合格，不允许按文案前缀猜。

## 7. 结算时序与账单

表示基线严格复刻当前顺序。下列统一快照顺序是语义版目标，会修正当前“先成长再读本场产速/容量”的差异：

1. 应战费、战前稿页消费等合法支付后，锁定战斗日常属性、稿页、容量、等级、历史、阶段；记录自然骰和操作来源。
2. 每次主动/购买先报价与合法性校验，再一次扣款。预览不消耗随机数，不修改状态。
3. 定稿冻结最终骰、已用主动、实际支付后的灵感；计算分数与奖励意图，不立即发资源。
4. 判胜负；处理尚未支付的败损和指定天象奖惩，不能再扣已支付应战费。
5. 基础回灵、心得及合格效果按资源和既定归并规则结算；同容量快照截断，账单保留逐来源名义值与总到账。
6. 熟练、研修、成稿按本战快照推进；完整结果页与成稿合页汇总后截断；新属性/容量对下一资源事件生效，不反向重算本步其他位。
7. 统一判断低灵感恢复资格、同类取高，合并发放后再补足底线。
8. 登记下一战状态、更新历史、掉落和后续选择；提交事务与已结算标记。

多个来源在同一截断前合并，若UI需要分摊实际到账，按稳定effectId顺序分摊并明确“展示分摊”；不能把这种分摊误作不同机制的价值测量。比较文心贡献应重算移除来源的结果。

## 8. 可核对的组合样例

以下为限定输入下的子系统结算样例，不是整局平衡结论；未列的额外效果均关闭。

### A. 诗胜心得：奖励很大也可能全部溢出

持有T001 Lv1、T012 Lv1及自动激活S38；以诗多骰获胜，阶段诗体已用过，无越级。基础心得3+T001的2+T012的3=8。学力11容量9，原心得5，实际+4，溢出4。S38加8%作品，不再发心得。没有额外的诗力+5；熟练和研修照常独立结算。

### B. 六点成稿：得分次数与资源次数分开

T007 Lv5、T040 Lv1及S10；最终骰[6,6,2]，多骰获胜。相关作品修正为32%+16%+10%=58%；三份成稿奖励各20格。笔力5、原进度15、本战被动5，共80格，按40合2页余0。基础多骰胜再给1页，合计名义3页。

若稿匣上限2、原有1页，实际只入1页、溢出2页。不得把溢出的整页留在进度中下战补领，也不得把本战新页反向加入T038算分。若只出现一枚6，三份成稿奖励仍各一次，但文心得分次数减少。

### C. 低开续掷：羁绊减费不能漏，触底也不能负价

T005 Lv1、T016 Lv1自动激活S04，诗体自然首骰2。第一枚追加骰：基础5−急智2−文思泉涌1−S04的1=1。若先润色再减2，仍实付1，润色此时没有边际省费；第二枚追加骰仍5。没有免费券时最低1。

自然序列[2,5,6]：T005得10%；T016两次连升各5%，再叠加满三骰10%，共20%并回灵1；S04首效果两枚追加骰得6%，低开高走另16%。只计算这些来源，作品修正合52%。润色与减费只改变支出，不额外多记一枚“未付费骰”。

### D. 换体：分数与心得分别取高

持有T037、TA02、T042，激活S13和S27；上一场为诗、本场词、上一场胜。T037修正8%、T042修正5%，S13的14%与S27的12%取高为14%，这些来源合27%。心得为T037的1，加S13/S27取高的2，共3。TA02持有足够激活成员，但未主动使用不扣费。

这例不包含S25；若没有T013、T014就不能让其16%参与。若为首战，所有换体效果都不触发。

### E. 非胜补偿：心得与下一战修正不重复进入旧属性路径

持有T027、T011，S21激活，本战败北且非阶段首次文体。基础心得2+T027的2+S21的2=6，容量再截断。下一战修正取max(4%,8%)=8%，在下次战斗锁定并消费一次。S21另一子效果只看上一场是否非胜，本战刚败不能倒流给已经完成的本战加分。

### F. 奇士累积：小奖励仍能保留长期价值

现有额外收入累积器初始0、灵感未满，连续五次各+1合格回灵，实际收入1、1、1、1、2，合计6；灵感余额仍整数。文心直接来源被当前资格规则排除时不增加该累积器。不能误把它迁移成灵感0.2余额。
