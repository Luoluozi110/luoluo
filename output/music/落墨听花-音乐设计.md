# 《文心棋》背景音乐：《落墨听花》

## 定位

为棋盘游历、阅读题目与构思作品设计的原创器乐主题。以游戏现有宣纸、桃花、墨色、印章及文学科举题材为依据：声音像书斋窗外的微风，琴声带着缓缓行走的节奏，箫声像想到一句诗时的轻吟。情绪清雅、温暖、略带求索感。

本次交付为原创曲谱、可复现的程序化合成小样及场景编配设计。WAV 可直接试听；尚未替换游戏内的音乐。古琴与箫均为合成音色意向，并非真实乐器录音，不能据此评价最终实录音质。

## 主曲规格

| 项目 | 设计 |
|---|---|
| 曲名 | 落墨听花 |
| 速度、拍号 | 66 BPM，4/4 |
| 调式 | C 宫五声音阶：C、D、E、G、A |
| 长度 | 32 小节，约 116.36 秒，循环 |
| 主奏 | 中低音区箫感音色，少量上行到 C5 |
| 伴奏 | 古琴感拨弦，单音与疏松呼应 |
| 点缀 | 开头和发展段各一次极轻钟音 |
| 空间 | 短而轻的反射，主体靠近，尾音留白 |
| 节奏 | 琴音疏密形成行进感，无持续鼓点 |

旋律动机为 **E—G—A—G｜D—E—C**，先抬头寻句，再低头落笔。每小节保留半拍至一拍的换气；8 小节一句，避免短循环不停重复。伴奏以 C、G、A 为落点，避免低音铺满阅读过程。

## 结构与配器

| 时间（约） | 小节 | 段落 | 听感与安排 |
|---|---|---|---|
| 0:00–0:14.55 | 1–4 | 展卷 | 琴声与极轻钟音，先建立空间 |
| 0:14.55–0:43.64 | 5–12 | 拾句 | 箫奏完整主题，琴在句间回应 |
| 0:43.64–0:58.18 | 13–16 | 留白 | 箫退场，仅留琴音，释放注意力 |
| 0:58.18–1:27.27 | 17–24 | 成章 | 主题回归，增加轻柔琴音，不用音量制造高潮 |
| 1:27.27–1:56.36 | 25–32 | 归砚 | 两个答句改由琴奏，末句回 C，接回展卷 |

最后一小节留一拍空隙，让尾音进入下一轮；导出时将混响尾部回卷到文件开头，文件内不加整曲淡出。程序化小样采用确定性合成，每次渲染得到相同曲谱与音频。

## 主旋律简谱

1=C；下列数字为音级，括号内为四分音符拍数，0 表示休止。除低音 6 和高音 1 外，均为 C4 所在八度。每行一小节，共 8 小节：

```text
3(1)   5(0.5) 6(0.5) 5(1) 0(1)
2(1)   3(1)   1(1.5)      0(0.5)
3(1.5) 5(0.5) 2(1)        0(1)
低6(1) 1(1)   2(1)        0(1)
5(1)   6(1)   高1(1)      0(1)
6(1.5) 5(0.5) 3(1)        0(1)
2(1)   3(0.5) 5(0.5) 2(1) 0(1)
3(1)   2(1)   1(1)        0(1)
```

## 场景变奏设计（后续接入规格）

保留同一主题和 66 BPM 拍点，用配器改变情绪。以下是设计要求，除主曲外尚未单独渲染或接入。

| 游戏场景 | 编配方式 |
|---|---|
| 主菜单 / 选流派 | 使用主曲主题，琴与箫建立记忆点 |
| 装配 / 阅读长文本 | 降低箫声，保留琴；少用钟音 |
| 棋盘游历 | 使用完整主曲，棋子落格与掷骰时短暂降低音乐 |
| 挥毫论道 | 保持拍速，增加中低音琴的八分音符回应及轻木击；箫只保留动机短句 |
| 殿试 | 在论道编配上增加低音支撑，每 8 小节一次钟音，保持克制 |
| 成卷 / 题名 | 将主题末句延长，琴与箫齐落 C，再转回稀疏伴奏 |
| 失利 / 再启 | 琴独奏主题后半句，减少高音，保留继续写作的余韵 |

旋律层在小节边界切换，增益约 1.2 秒渐变；强反馈可立即闪避。继续使用现有 `audio.js` 的共享总线、静音记忆与首次交互解锁机制。不要叠播现有旋律与新主题。

现有 `music.js` 已有场景分层，但待机旋律仅 4 小节，棋盘场景旋律层为 0。若实现本方案，应改为长句结构或加载可循环音频。当前长音垫与 drone 的调度未限定在小节首拍，接入时需避免每个八分音符重新叠加整小节长音；静音或后台恢复时也应重定位调度时间，避免补播积压事件。

阶段成长宜用音区和织体变化表现；现有按半音整体移调会改变整套音阶，并不是始终保持 C 宫调内音，不能直接作为“调内移调”的依据。

## 制作与验收

小样使用 22.05 kHz、16-bit、双声道 PCM WAV，峰值目标 -3.1 dBFS 左右；最终乐器采样或实录版本建议采用 48 kHz、24-bit 母带，再输出浏览器交付格式。最终响度应与现有 SFX 实际混听后确定，不能直接用峰值代替响度判断。

自动验证：每小节 4 拍、32 小节时长、事件数量、音频头、削波样本数和循环边界跳变，结果见 `validation.json`。这些检查不替代人工试听。

人工验收建议：连续循环三次；阅读题目时能保持专注；掷骰与答案反馈清楚；耳机与手机扬声器均无刺耳高音；循环接缝没有点击或明显抽空。进入游戏后另验场景过渡、后台恢复与静音行为。本次未进行游戏接入验收或真实乐器录制。

重新生成：在项目根目录运行 `python output/music/render_luomo.py`。`score.json` 保存全部音符、节拍、时值、音量和声像，可作为后续制作输入。
