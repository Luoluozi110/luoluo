NARRATIVE REVIEW · 飞花棋

《飞花棋》文案优化评审稿

评审基线：`feihuaqi-playable/` 网页版实际可玩构建 · 仅做文案与叙事评审，不改代码 / 配置 / 数值
范围：流派选择 · 奇遇 · 传世名篇 · 文心 · 天象 · 题库解析 · NPC 机制提示 · 战斗流程 · HUD 与结算
一句话判断：现有文案有文化、有画面、规则清楚；下一阶段要补的是有动机、有关系、有回声。

一、现有优势

1. 世界的语汇已经形成

“科场、文心、灵感、文体、文风、风潮、金榜、殿试、图鉴阁”彼此支撑，几乎没有现代网游式的突兀跳出。`motto + flavor` 把三派从属性入口提升成三种写作人格：

博闻

以积累和引证为力量，知识即笔力。

奇士

以偏锋和突破解局，灵机即转机。

辞宗

以落笔与表达压场，言辞即锋芒。

后续应沿着「不同的写法 = 不同的看世界方式」继续深化。

2. 奇遇卡已有场景感

「卖字换酒」「老农问字」「落第榜下」「病中得句」都有明确的地点、动作与代价；其中「落第榜下」尤其接近游戏叙事——把失败、历史典故与下一次行动放在同一情境。

3. 机制反馈不是纯数字

mechHints.js 已把 NPC 机制翻译成「所长 / 所短 / 行藏」，结算会告诉玩家“正中破绽”或“招牌未遭针对”。这是玩法系统可被叙事化的关键接口。

4. 题目解析有教育价值

题库不止给答案，还解释作者、上下文、干扰项与识别方法，适合做「学完一题，顺便记住一个世界细节」的知识循环。

二、优先级总表

优先级问题影响建议落点
P0缺少贯穿全局的主角动机与阶段回声玩家知道在走格子，不一定知道在经历什么开局、三阶段过渡、殿试、结算各补 1 段短叙事
P0奇遇选择大多只改奖励，缺少可感知后果选择容易退化为“哪边数值高”choice 增加 resultText，必要时加轻量状态标签
P1典故密度高，主叙事常被出处打断有文化但不够贴身，像在读注释主文案先写“此刻发生什么”，出处移到次级信息
P1NPC 有机制名，缺个人声音对手像模板集合，不像“人”增加 intro / winLine / loseLine / weaknessLine
P1战斗流程文案偏系统术语规则能懂，情绪不够标题从“机制结算”改成“交锋回响 / 察招结果”等
P2题库与界面存在语体断裂古风世界偶尔被现代表达拉出戏清理现代选项，统一时代语域
P2长短不均、句式重复高频游玩后出现“同一张卡的感觉”建字数、句式、意象、结尾动作的内容规范

三、最终建议排序（若只能做三件事）

1

给 choice 增加 resultText，让选择产生即时回声

选择不再是“选哪边奖励”，而是玩家确实做了一件事。

2

给具名 NPC 加一句登场动作与一句战后反应

让机制名背后先站一个人，再谈数值。

3

补开局、阶段过渡、殿试、结算四个短叙事节点

建立“赶考的一程”的整体感。

三项均不重做玩法，却能把游戏从「古典题材策略卡牌」推向「玩家正在经历一段自己的科场故事」。

四、P0 · 叙事主线

最小主线（四段式叙事回路）

你不是为了证明自己“懂得最多”，而是要在一路遇见的人和事里，找到属于自己的落笔之道，并把它带到金殿。

这句话不必原样展示，但应成为全部文案的判断标准。

  • 开局——你为何赴考：县试放榜那日，先生没问你能不能中，只问：“若这一回仍无人看见你的文章，你还写不写？” 你收好行囊，往京城去。
  • 乡试圈——认识自己的写法：博闻「你记下了这句。还未成篇，却已在腹中生根。」／奇士「众人都往前走，你偏从旁处看了一眼。灵机因此留下。」／辞宗「这一笔没有白落。纸面不语，功夫记得。」
  • 会试圈——让对手成为镜子：只信熟路的人 / 宁可不惊人也不肯失手的人 / 看似学你实则逼你换一个自己的人。
  • 殿试——让前面的选择回来：王侍郎“跨场适应”承接主线回声：
    连续用同一文体：「前两场皆以一锋破题，今日还要走旧路么？」
    主动换体：「知道换笔，才知道守成不是本事。」
    曾经高分压卷：「你上回以势压人，今日可还压得住自己的急？」

五、P0 · 让选择产生回声

最小改法：每个选择增加一条 1—2 句的结果回声，在奖励结算后显示或写入战报。建议字段：

{
  "text": "还他五色笔，从此老实读书",
  "resultText": "你把五色笔放回枕边。梦醒时，手中空了，心里却多了一点自己的分量。",
  "effect": { "attrs": { "si": 3 }, "inspiration": -5 }
}

示例 · E006「江郎才尽」

梦里，郭璞来索那支寄放多年的五色笔。他不催，只伸着手。窗外风过，案上旧稿一页页翻动，像是在替你回答：这些年写下的，究竟有多少是自己的？

  • 还他五色笔，承认自己还差得远 → 五色光从指间退去。你重新铺纸，第一笔写得很慢，却没有借谁的声名。
  • 强留彩笔，再逼自己写出一篇 → 你攥紧那支笔，连夜搜尽枯肠。天亮时文章成了，墨色却像从骨头里榨出来的。

两条路不再是“思力换灵感 / 笔力换灵感”，而是“承认不足”与“以透支换锋芒”。

六、P1 · 典故服务当下

采用三层典故结构：现场层（看见什么、做什么、失去什么）→ 意义层（让你想到什么、逼你作何选择）→ 出处层（历史典故 / 原句 / 作者）。

当前不少奇遇从出处层开始；建议把出处放到卡片次级区域，主文案先让玩家进入现场。典故不删——它是《飞花棋》独特资产——但从“主持人讲解”退到“玩家发现的知识层”。

推荐格式

标题：推敲之苦
主文案：你在一个字上停了三日。写下去，似乎不妥；删掉它，又觉得整篇少了一口气。
选择：留在案前把这个字磨到天明 / 先放下笔让文章喘一口气
典故：贾岛曾在「推」与「敲」之间反复斟酌……（次级区）

长度建议：common 60–100 字 · rare 80–130 字 · legend 100–160 字（超出拆主文案+次级典故）。

七、P1 · 给 NPC 加“人声”

当前开场较统一（“某某拦路请教”）。不给每个 NPC 写长传记，每个具名 NPC 只加 3—4 条短句即可：

{
  "id": "zhou_xiaoman", "name": "周小满", "title": "蒙学童子",
  "intro": "周小满把卷子抱在胸前，先看了看你的笔，又偷偷看了一眼自己的。",
  "winLine": "他抿着嘴，把错题一一记下，临走还回头问你那个字怎么写。",
  "loseLine": "他笑得很快，像是早知道这一场会输，却仍把卷子递了过来。",
  "weaknessLine": "你换体落笔后，他明显愣了一下：原来文章还可以这样写。"
}

NPC 声音方向

类型声音关键词不应说成
童生直白、好胜、偶尔嘴硬老成的“本官/在下深谙”
秀才讲究体面、会绕弯、有比较心只会报机制的系统提示
举人自信、会试探玩家、懂得留手数值更高的秀才
进士克制、精确、话少但有压力夸张的江湖挑衅
主考官不轻易表态，以批注和停顿施压连续解释规则

机制名也可更贴近人物习惯：识破重复→「看穿旧路」、稳稿压迫→「不失一字」、追加骰→「见势加锋」、文债耗神→「余墨被催干」。底层模板名保留，玩家可见名传达情绪与行为。

八、P1 · 战斗 UI 从系统阶段转向玩家动作

当前建议副标题玩家正在做
② 审题② 先定其意决定我如何理解题目
③ 选文体③ 选择落笔之体决定我用什么形式说话
④ 选风格④ 定下文章气口决定我以何种情绪说话
⑤ 掷灵感骰⑤ 看这一笔起势决定临场爆发与资源投入
⑥ 算分对决⑥ 卷面相见看双方写法如何碰撞

高频 UI 替换：机制结算 → 交锋回响；招牌·破绽·修正 → 你如何破招，对手如何应变；确定得分 → 定稿落笔。

胜：这一笔落定，对方的卷面静了。你赢的不是声势，是把所选的路走到了尽头。

负：这一场，你的句子没能压住他的锋。别急着收笔——榜还在前头，下一场可换一条路。

平：两卷相持，胜负只差一线。你们都没有写错，只是这一回，谁也没有写到最后。

九、P2 · 统一时代语域

  • 拍下来发给同窗看 → 摹下此景，寄与同窗共赏
  • 只看风景，不写一字 → 记住此景，暂不落笔

原则：错误选项可以不高雅，但不能穿越。

普通玩家入口只显示“玩法设置 / 内容版本”；“配置来源”与自定义 JSON 说明移入“高级”弹窗；结算页尽量不出现“维度、参数、回退、机制”等工程词。

第二人称保留，但避免每句都以“你”开头：石桥尽头，河灯一盏盏顺水而下。故乡的秋夜，也该是这样的光。

十、新内容自查规范摘要

奇遇卡：至少含一个看得见的物件 + 一个正在发生的动作 + 一个与玩家有关的压力/诱惑；choice 两选须代表不同价值取向而非奖励高低；每选一条回声；典故最多承担一项功能。

NPC：一句登场动作 + 一句胜负后反应 + 一句破绽被击中时的反应 + 一个“他不会说”的禁语或语气约束。

战斗反馈：按「发生了什么 → 为什么发生 → 玩家因此获得什么启示」三段写。

题库解析：首屏先给一句答案与记忆钩子，长解析拆“为什么对 / 为什么容易错”，避免每题变成同一种结构。

十一、最小实现批次

批次内容风险
A
只改字符串		重写高频字符串、10–15 张常见奇遇首段、清理题库现代选项、战斗标题、胜负句、弱化普通玩家可见的“配置来源”最低
B
加字段		choices[].resultText、npcs[].intro、winLine/loseLine/weaknessLine、questions[].analysisShort——全部可选、缺省沿用旧文案很小
C
系统增强		三阶段过渡短场景、选择状态标签、殿试定向评语、图鉴个人战绩注记待 A/B 验证后

当前系统更适合短回声 + 跨场记忆，不建议一开始就做大规模分支剧情。

十二、验收清单（摘）

  • 玩家不看典故出处，也能理解当前发生了什么
  • 开局说明“为什么出发”，结算回应“这一程留下了什么”
  • 每个 choice 两项在价值上不同，而不只是奖励不同
  • 选择后 1 个界面内能看到文本回声
  • 去掉名字仍能凭说话方式区分连续三名 NPC 中的至少两人
  • 没有现代手机、社交媒体或后台配置词汇穿透古风场景
  • 战斗阶段标题既能说明规则，也能说明玩家正在做的叙事动作
