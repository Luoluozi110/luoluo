## 二、导入步骤

1. 打开微信开发者工具，**用微信扫码登录**（必须，游客模式无法用云开发）。
2. 左侧选「小程序」，点右侧的 **「+」或「导入项目」**。
3. **目录**：选择 `feihuaqi-miniprogram` 这一层。

   ⚠️ 最常见的错误就是选到了父目录。判断标准很简单——
   打开目录能直接看到 `app.json`、`project.config.json`、`pages/`，就对了。

4. **AppID**：
   - 有正式 AppID → 填进去（**要用云开发就必须填真实 AppID**）
   - 只是想先看看界面 → 可以选「测试号」，但云开发相关功能会全部不可用
5. **后端服务**：需要榜单就勾选「小程序·云开发」。
6. 点「导入」。

导入后如果工具提示 `appid` 与 `project.config.json` 不一致，按提示同步即可。

---

## 三、导入后必做的四件事

### 1. 把 appid 换成正式值

`project.config.json` 里当前是占位值：

```json
"appid": "touristappid"
```

改成真实 AppID 后重启工具。带 `touristappid` 上传会失败。

### 2. 开通云开发

工具栏「云开发」→ 新建环境（有免费额度）。
建好后确认 `project.config.json` 的 `cloudfunctionRoot` 指向 `cloudfunctions/`—— 本项目已配好。

### 3. 上传四个云函数

`cloudfunctions/` 下每个目录右键 → **「上传并部署：云端安装依赖」**：

```
authLogin   getRank   submitScore   trackChannel
```

集合不用手动建——云函数内置了自愈，首次调用会补建。

### 4. 调试阶段勾上「不校验合法域名」

本地设置里勾选。否则本地调试会被域名校验拦住。
**上线发布前记得取消勾选。**

## 四、首次编译可能遇到的情况

| 现象 | 原因 | 处理 |
|---|---|---|
| 「未找到 app.json」 | 目录选到了父级 | 重选到 `feihuaqi-miniprogram` |
| 编译卡住十几秒 | `engine/` 836KB + 配置 348KB，首次解析较慢 | 正常，等它跑完；之后是增量编译 |
| 控制台报 `wx.cloud` 相关 | 云开发未开通 | 正常降级，云调用静默失败，单机玩法不受影响 |
| 分包页面空白 | `pkg-*` 里的图鉴阁 / 入门卷 / 设置仍是占位页 | 已知状态，不影响主流程 |
| 提示基础库版本低 | `libVersion: 3.5.0` | 可在「详情 → 本地设置」调到较新版本 |

## 五、导入成功后应该看到什么

按顺序走一遍，确认主链路正常：

- [ ] 编译无报错，模拟器显示**主菜单**（标题「文心棋」）
- [ ] 点「开始游戏」→ **选流派**：博闻 / 奇士 / 辞宗
- [ ] 选一个 → **装配屏**：12 张传世名篇，新账号全部未解锁（会显示各自的解锁条件）
- [ ] 起名 → 进**对局**：六维、灵感条、落点、回合数都在
- [ ] 点「下一步」→ 出现答题 / 奇遇 / 战斗台等对话框，都能正常操作
- [ ] 「自动推演到结算」→ 走到结算页，显示总分与段位
- [ ] 回主菜单，「继续游戏」此时应为不可用（上一局已结算并清档）
- [ ] 开一局走到半途退到主菜单 → 「继续游戏」应可用且能接着下
- [ ] 进「榜单」：未开云时显示离线提示，而不是白屏

云开发的端到端验证另见 `CLOUD-SETUP.md` 第七节。
